One original dad joke, a single line of at most 140 characters — a dad's classic "uphill both ways" school walk, fact-checked by his son on Google Maps — written deterministically to `/output/entry.txt` for make.fun's "The One-Liner Groan-Off" bounty.

## Run it

```sh
python3 main.py
```

Outside the grader, set `MAKEFUN_OUTPUT_DIR` to choose where `entry.txt` is written (default `/output`).
